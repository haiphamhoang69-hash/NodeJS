BÀI 3 - BÀI TẬP 01: QUẢN LÝ DANH SÁCH SINH VIÊN
1. Mục tiêu
Sử dụng class và constructor để tạo đối tượng sinh viên.
Khai báo danh sách gồm 5 sinh viên.
Sử dụng arrow function để lọc sinh viên có điểm từ 5 trở lên.
Sử dụng console.log() để hiển thị danh sách sinh viên đạt yêu cầu.
2. Nội dung chương trình

Tạo file bai01.js chứa chương trình quản lý danh sách sinh viên.

Chương trình sử dụng class SinhVien để khai báo các thuộc tính gồm mã sinh viên, họ tên, tuổi và điểm.

Sau đó tạo danh sách 5 sinh viên và sử dụng hàm filter() kết hợp arrow function để lọc những sinh viên có điểm từ 5 trở lên.

Cuối cùng sử dụng console.log() để hiển thị kết quả trong Terminal.

3. Các bước thực hiện

Bước 1: Mở thư mục Bt01 bằng Visual Studio Code.

Bước 2: Tạo file bai01.js và nhập đoạn code chương trình.

Bước 3: Mở Terminal trong Visual Studio Code.

Bước 4: Chạy chương trình bằng lệnh:

bash
node bai01.js


Bước 5: Kiểm tra kết quả hiển thị trong Terminal.

4. Kết quả thực hiện

Chương trình chạy thành công và hiển thị danh sách sinh viên có điểm từ 5 trở lên.

Có tổng cộng 3 sinh viên đạt yêu cầu.

5. Hình ảnh minh họa
Hình 1: Code chương trình bai01.js

Chèn ảnh chụp màn hình code tại đây.

Hình 2: Chạy chương trình trong Terminal

Chèn ảnh chụp màn hình lệnh node bai01.js tại đây.

Hình 3: Kết quả cuối cùng

Chèn ảnh chụp màn hình danh sách sinh viên đạt yêu cầu tại đây.

6. Kết luận

Đã hoàn thành bài tập quản lý danh sách sinh viên bằng Node.js. Biết cách sử dụng class, constructor, arrow function và filter() để lọc sinh viên có điểm từ 5 trở lên. Chương trình chạy thành công và hiển thị đúng kết quả trong Terminal.
