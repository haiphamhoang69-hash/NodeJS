# BÀI 4: XÂY DỰNG WEB VỚI EXPRESS FRAMEWORK

## 1. Giới thiệu
Bài thực hành tìm hiểu và xây dựng ứng dụng Web bằng Node.js kết hợp với Express Framework.

## 2. Nội dung thực hiện
- Tìm hiểu Web Application Framework và mô hình MVC.
- Tạo ứng dụng Express cơ bản.
- Thực hành Route.
- Thực hành Middleware.
- Sử dụng Template Engine Pug.
- Sử dụng Template Engine Handlebars.
- Thực hành xử lý lỗi (Error Handling).
- Xây dựng ứng dụng máy tính theo mô hình MVC.

## 3. Công nghệ sử dụng
- Node.js
- Express.js
- Pug
- Handlebars
- Body-parser
- HTML, CSS

## 4. Cài đặt thư viện
```cmd
npm install express pug body-parser express-handlebars
```

## 5. Các lệnh chạy chương trình

```cmd
node app.js
node express_route.js
node express_middleware.js
node express_pug.js
node express_handlebars.js
node express_errorhandling.js
node my-express-app/app.js
```

Mỗi chương trình được chạy riêng trên cổng 3000. Nhấn `Ctrl + C` để dừng chương trình hiện tại trước khi chạy chương trình tiếp theo.

## 6. Kết quả thực hiện
- Chạy thành công ứng dụng Express cơ bản.
- Thực hiện được các chức năng Route và Middleware.
- Hiển thị giao diện bằng Pug và Handlebars.
- Kiểm tra chức năng xử lý lỗi.
- Xây dựng và chạy ứng dụng máy tính theo mô hình MVC.

Các kết quả được kiểm tra trực tiếp trên trình duyệt thông qua địa chỉ `http://localhost:3000`.

## 7. Kết luận
Qua bài thực hành, em hiểu được cách xây dựng ứng dụng Web với Express Framework, cách sử dụng Route, Middleware, Template Engine, xử lý lỗi và tổ chức chương trình theo mô hình MVC.
