BÀI 01: XÂY DỰNG WEBSITE GIỚI THIỆU CÁ NHÂN BẰNG EXPRESS
1. Giới thiệu

Bài thực hành xây dựng website giới thiệu cá nhân sử dụng Node.js kết hợp với Express Framework. Website giới thiệu thông tin cá nhân, kỹ năng, sở thích và thông tin liên hệ của sinh viên Phạm Hoàng Hải.

2. Nội dung thực hiện
Khởi tạo dự án Node.js.
Cài đặt và sử dụng Express Framework.
Xây dựng các Route: /, /about, /skills, /hobbies, /contact.
Thiết kế giao diện website bằng HTML và CSS.
Xây dựng menu điều hướng giữa các trang.
Xử lý đường dẫn không tồn tại bằng HTTP 404.
Khảo sát các dịch vụ hosting miễn phí hỗ trợ Node.js.
Triển khai website lên Render.
3. Công nghệ sử dụng
Node.js
Express.js
HTML5
CSS3
GitHub
Render
4. Cài đặt thư viện
cmd
npm init -y
npm install express

5. Lệnh chạy chương trình
cmd
npm start


Sau khi chạy thành công, truy cập địa chỉ:

http://localhost:3000

6. Kết quả thực hiện trên máy cá nhân (localhost)
Hiển thị giao diện trang chủ.
Hiển thị trang giới thiệu cá nhân.
Hiển thị trang kỹ năng.
Hiển thị trang sở thích.
Hiển thị trang liên hệ.
Xử lý lỗi khi truy cập đường dẫn không tồn tại (HTTP 404).

7. Kết quả thực hiện
Xây dựng thành công website giới thiệu cá nhân bằng Express Framework.
Các trang chủ, giới thiệu, kỹ năng, sở thích và liên hệ hoạt động bình thường.
Menu điều hướng giữa các trang hoạt động chính xác.
Xử lý thành công lỗi HTTP 404 khi truy cập đường dẫn không tồn tại.
Giao diện website hiển thị tốt trên máy tính và điện thoại.
Triển khai website lên nền tảng Render.
